📊 Starbucks Beverage Analysis Dashboard (Power BI)
📌 Project Overview

This project focuses on analyzing Starbucks beverage data using Power BI to uncover insights related to calories, sugar, caffeine, and beverage distribution.

The goal was to transform raw data into an interactive dashboard that supports better understanding of product composition and customer health trends.

🎯 Objectives
Analyze nutritional metrics across beverage categories
Identify high-calorie and high-caffeine drinks
Compare beverage categories using interactive visuals
Build a clean, business-oriented dashboard for decision-making
📂 Dataset
Contains 32+ Starbucks beverages
Features include:
Beverage Category
Calories
Sugar (g)
Caffeine (mg)
Protein
🛠 Tools & Technologies
Power BI – Dashboard development
DAX – Calculated measures & KPIs
Data Cleaning – Handling inconsistencies & formatting
📊 Dashboard Features
🔹 KPI Cards
Total Beverages: 32
Average Calories: 196.17
Average Sugar: 33.29g
Average Caffeine: 86mg
🔹 Visualizations
Average Calories by Beverage Category (Line Chart)
Beverage Category Distribution (Donut Chart)
Starbucks Global Presence (Bar Chart)
Average Caffeine by Category (Bar Chart)
Top 5 Highest Caffeine Drinks
🔹 Interactivity
Protein range slicer
Beverage category filters
Dynamic visual updates
🔍 Key Insights
☕ Coffee beverages contain the highest caffeine (~294mg)
🥤 Smoothies & frappuccinos are higher in calories
🍬 Sugar levels vary significantly across categories
📊 Espresso-based drinks dominate category share
💡 Business Impact
Helps identify health-conscious product options
Supports menu optimization strategies
Enables quick comparison of nutritional values
Demonstrates how data can drive customer-focused decisions
